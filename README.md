# Watta Sushi App 🍣

Мобильное приложение для заказа суши, написанное на Flutter. Приложение связано с рабочим бэкендом (Node.js + Prisma) и поддерживает мультиязычность, корзину, профиль пользователя и историю заказов.

## 🛠 Предварительные требования (Prerequisites)
Убедитесь, что у вас установлены:
1. [Flutter SDK](https://docs.flutter.dev/get-started/install) (версия 3.x и выше)
2. Dart SDK (идет в комплекте с Flutter)
3. Редактор кода (VS Code или Android Studio)
4. Настроенный эмулятор Android/iOS или браузер Chrome для веб-тестирования.

## 📦 Рекомендуемые расширения для VS Code
Для комфортной работы с проектом рекомендуется установить следующие плагины:
* **Flutter** (официальный плагин)
* **Dart** (официальный плагин)
* **Error Lens** (для удобного отображения ошибок в строке кода)
* **Awesome Flutter Snippets** (для быстрого создания виджетов)

## 🚀 Установка и запуск

### 1. Клонирование репозитория
```bash
git clone [https://github.com/ITty-Company/watta-sushi-app.git](https://github.com/ITty-Company/watta-sushi-app.git)
cd watta-sushi-app.

### 2. Установка зависимостей
Загрузите все необходимые пакеты (Provider, Http, Shared Preferences, Slang и др.):
```bash
flutter pub get

### 3. Генерация переводов
Проект использует пакет slang для мультиязычности. Исходные файлы переводов лежат в lib/i18n/ в формате .i18n.json.
После клонирования репозитория или добавления новых слов в JSON-файлы, обязательно выполните команду для генерации Dart-кода:
```bash
dart run slang

### 4. Запуск приложения
Вариант А: Запуск на мобильном эмуляторе / физическом устройстве (Рекомендуется)
Просто нажмите F5 в VS Code или выполните:
```bash 
flutter run

Вариант Б: Запуск в вебе (Chrome)
Бэкенд приложения имеет защиту CORS, которая блокирует неизвестные порты. Чтобы локальный Flutter-веб смог получать данные, его нужно запускать строго на порту 3000:
```bash 
flutter run -d chrome --web-port 3000
